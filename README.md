# ДЭ 2027 · Программист

Подготовка студентов 09.02.07 «Информационные системы и программирование», квалификация «Программист», по КИМ 09.02.07-2-2027. Образец «Чудо Обувь»: база данных, каталог, оформление заказа и управление заказами.

Методика для четырёх инвариантных заданий проверена в Windows. Семь форм созданы в Visual Studio Designer, таблицы и связи — в DBeaver. Release-сборка запущена на восстановленной базе. [Открыть курс](https://olgakraven.github.io/2027-prog-demo/).

## Учебные разделы

- Обучение: условие, подготовка и четыре задания. На карте можно выбрать Windows Forms + MySQL / MariaDB или WPF + PostgreSQL.
- Тренировка: официальный образец и пауза.
- Пробный экзамен: 30 авторских учебных вариантов инвариантного ядра.
- Примеры: решения для обоих стеков, SQL, ER и исходные данные.
- Критерии: инвариантная часть.
- Преподавателю: отдельная презентация по учебным шагам каждого стека.

Гость просматривает каталог; пользователь входит по логину без пароля. Менеджер и администратор управляют заказами. Приложение рассчитывает скидку по предыдущему календарному месяцу, хранит остатки по размерам, сохраняет и отменяет заказы транзакционно.

Базовый уровень включает четыре задания на 210 минут и 75 баллов. Для пробного экзамена подготовлены 30 учебных вариантов.
