# ДЭ 2027 · Программист

Подготовка студентов 09.02.07 «Информационные системы и программирование», квалификация «Программист», по КИМ 09.02.07-2-2027. Образец «Чудо Обувь»: база данных, каталог, оформление заказа и управление заказами.

## Учебные разделы

- Обучение: условие, подготовка и четыре задания.
- Тренировка: официальный образец и пауза.
- Пробный экзамен: 30 авторских учебных вариантов инвариантного ядра.
- Примеры: программное решение C# Windows Forms + MySQL/MariaDB, SQL, ER и исходные данные.
- Критерии: инвариантная часть.
- Преподавателю: презентация по учебным шагам.

Учебный маршрут требует создания форм в визуальном конструкторе Visual Studio, а таблиц и связей — в конструкторе СУБД. Текущий исполняемый пример пока использует ручное построение интерфейса и переносится на Designer; полный проход обновлённой методики ещё не подтверждён. Гость просматривает каталог; пользователь входит по логину без пароля. Менеджер и администратор управляют заказами. Приложение рассчитывает скидку по предыдущему календарному месяцу, хранит остатки по размерам, сохраняет и отменяет заказы транзакционно.

Профильный уровень включает вариативную часть образовательной организации. Утверждённого Тома 2 в предоставленном комплекте нет; проект не выдаёт инвариантный образец за полный профильный экзамен. Норматив инвариантного ядра: 210 минут, 75 баллов. Учебные варианты не являются официальными вариантами ДЭ.

## Разработка и проверка

Веб-курс: Node.js, `npm run prepare:data`, `npm run build`, `npm test`, `npm run preview`. Первое преобразование ER: Python 3 с reportlab, `python3 scripts/diagram.py`. При Windows используйте `py -3` вместо `python3`. У diagram.py параметр шрифта задаётся переменной `PROG_DEMO_FONT`, если Arial не найден стандартно.

Готовый пример: откройте `ProgDemo.sln` в Visual Studio с .NET desktop development и .NET 10. Импортируйте `content/sample.sql` в новую пустую учебную MySQL; не запускайте повторно поверх заполненной базы. При старте приложение предложит реквизиты подключения. Они не сохраняются в файле. Дополнительно поддерживается `PROG_DEMO_CONNECTION` в локальном профиле запуска. Не включайте пароль в Git.

Для контрольной даты задайте `PROG_DEMO_DATE=2026-05-15`; без неё используется текущая дата. Исходные заказы датированы 2026 годом и не переписываются. Интеграционные проверки `examples/Checks` разрешены только в отдельной базе с префиксом `prog_demo_checks`; настройки берутся из `PROG_DEMO_CONNECTION`. В Windows передайте путь JSON-отчёта первым аргументом, если нужно сохранить результаты.

Оригинальные PDF/ZIP, изображения и XLSX сохраняются в `materials`. Происхождение и контрольные суммы — `docs/source-manifest.json`, решения импорта — `docs/import-decisions.md`. Учебная оболочка основана на `OlgaKraven/2027-dkip-demo`, commit `6427060c45e51b307f4cc047f58aaa674623f8a8`; предметные требования взяты из КИМ `-2`, не из КИМ `-5`.

Маршрут через конструкторы и границы проверки: [формы и БД](docs/Designer-route.md).
