Запуск готового примера

  1. Откройте ProgDemo.sln в Visual Studio с компонентом .NET desktop development и .NET 10. Готовый пример уже содержит ссылку на Core и закреплённый пакет MySqlConnector.
  2. В XAMPP запустите MySQL; в phpMyAdmin импортируйте content/sample.sql в новую пустую базу. Скрипт не предназначен для повторного импорта в заполненную базу.
  3. Проверьте 31 модель, 92 позиции, 20 пользователей, 10 заказов и 30 строк. Сохраните SQL и ER PDF рядом с решением.
  4. В Solution Explorer выберите ProgDemo.WinForms как Startup Project. Нажмите F5.
  5. Введите сервер, порт, базу prog_demo_sample, пользователя и пароль вашей СУБД. Это не реквизиты клиента магазина. Значения формы подключения не сохраняются на диск.
  6. Откроется гостевой каталог. Для оформления заказа нажмите «Войти / сменить пользователя» и введите asidorova. Пароль не нужен.
  7. Выберите модель, доступный размер и количество. Добавьте несколько позиций, откройте «Мой заказ». Измените или удалите строку и подтвердите заказ.
  8. Для менеджера используйте papetrov, для администратора isivanov. Список и состав заказов доступны через «Заказы клиентов»; дата и удаление строк — только администратору.
  9. Для проверки обеих ветвей скидки задайте PROG_DEMO_DATE=2026-05-15 в локальном профиле запуска Visual Studio. Для текущей даты удалите эту переменную.
  10. При ошибке подключения проверьте MySQL, имя базы и импорт. При нехватке товара обновите каталог и уменьшите количество.
  11. Выполните Release Build. Скопируйте всю папку вывода вместе с DLL и Assets; для запуска нужен .NET Desktop Runtime 10. Для Windows ARM64 используйте соответствующий режим публикации.
  12. Пароли, launchSettings.json, .vs, obj и пользовательские настройки не включайте в Git. Исходники, SQL с данными, ER и README передаются структурой.
