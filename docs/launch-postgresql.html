Запуск примера WPF + PostgreSQL

1. Восстановите учебную базу

  1. Распакуйте ZIP примера целиком. В pgAdmin подключитесь к запущенному PostgreSQL и создайте пустую базу prog_demo_sample с кодировкой UTF-8.
  2. Откройте Query Tool именно для новой базы. Загрузите content/postgresql/sample.sql и выполните весь скрипт. Он создаст таблицы, загрузит исходные записи и установит следующие номера заказов.
  3. Обновите таблицы и сверьте количество строк: 31 модель, 92 размерные позиции, 35 размеров, 20 пользователей, 10 заказов и 30 строк заказа.

2. Откройте приложение

  • Если в ZIP есть папка Windows, установите .NET Desktop Runtime 10 для архитектуры сборки и запустите Windows/ProgDemo.Wpf.exe. Оставьте DLL и Assets в той же папке.
  • Для сборки из исходников откройте ProgDemo.PostgreSql.slnx в Visual Studio с .NET 10 SDK и компонентом разработки классических приложений .NET. Назначьте ProgDemo.Wpf стартовым проектом и нажмите F5.

В окне подключения укажите адрес, порт и реквизиты PostgreSQL. Имя базы — prog_demo_sample. После подключения откроется гостевой каталог. Для контрольной даты скидки задайте PROG_DEMO_DATE=2026-05-15 в локальном профиле запуска.

3. Проверьте заказ

  1. Войдите по учебному логину asidorova. Найдите модель, выберите категорию и сортировку, откройте карточку модели щелчком по строке.
  2. Добавьте две размерные позиции. Измените количество в «Мой заказ», подтвердите заказ и сверьте остатки.
  3. Войдите как papetrov и найдите заказ в списке. Войдите как isivanov, измените дату и удалите строку. Сверьте итог заказа и остаток.

4. Подготовьте данные для своего варианта

В новой пустой базе создайте таблицы по content/postgresql/schema.sql. Назначьте ProgDemo.Import стартовым проектом и нажмите Ctrl+F5. Укажите папку с XLSX либо CSV, новую папку для результата и --postgres. В Query Tool целевой базы выполните полученный data.sql.
