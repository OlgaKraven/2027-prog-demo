# Решения импорта

Оригиналы неизменны. Точный ключ модели — название и производство, после нормализации пробельных символов только для сопоставления. У женских туфель имеется неразрывный пробел; у «Азимут Бег» — краевой пробел. Сокращённое «Черные туфли в классическом стиле», производство «Барбари», явно сопоставлено с «Черные туфли в классическом стиле — база для деловых образов». Это учебное допущение, а не исправленный официальный источник.

Заголовок «Отчетсво» сопоставляется с отчеством. Исходное имя «Пeтр» сохраняется. Дробные размеры хранятся без округления. В итоговом импорте 31 модель, 92 позиции, 35 размеров, 20 пользователей, 10 заголовков и 30 строк заказов.

Исходный файл остатков означает уже доступный остаток. Импорт истории повторно не списывает склад: у исходных заказов stock_accounted=0; у новых подтверждённых — 1. При удалении возвращается только действительно списанный остаток. Это выбранное правило воспроизведения исходных файлов, обозначенное отдельно от функциональных требований КИМ.

roles, идентификаторы, request_id и created_by — технические решения. Логин сравнивается точно после удаления краевых пробелов ввода, пароль не требуется. Вызовы операций повторно читают роль из БД. Это учебная локальная модель из задания, не удалённый сервис авторизации.

Исторические цены остаются в строках заказов. Новая цена рассчитывается decimal с округлением до копеек. Предыдущий месяц — полуинтервал от первого числа прошлого месяца до первого числа текущего. В мае 2026 проверяются апрельские заказы по всем размерам модели.

Авторские варианты используют разные предметные области и сохраняют структуру базы и функциональные требования задания. Названия, цены, остатки и логины согласованы внутри каждого комплекта. Данные в JSON/CSV являются производными учебными источниками. Готовый SQL варианта доступен в исходниках проекта для сверки, но не включён в скачиваемый экзаменационный ZIP. Контрольные расчёты разработчика не публикуются в условиях.
