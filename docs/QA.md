# Проверка первой версии разработки

5 ноября 2026 года. Эта версия запускает разработку отдельного курса «Программист». Она не является приёмкой полного профильного экзамена без утверждённого Тома 2.

## Выполнено

- C# WinForms и Core собраны на Mac с Windows targeting; окончательная Debug/Release-сборка также выполнена в Windows 11, SDK 10.0.402, без ошибок и предупреждений.
- В отдельной MariaDB на существующем порту учебного сервера выполнены 14 проверок: 3 чистых правила и 11 сценариев с настоящей БД. Проверены полный исходный импорт, вход по логину, неизвестный/инъекционный ввод, обе ветви скидки, совместные поиск/категория/сортировка, права и их повторная проверка из БД, неверные количества, откат частичного заказа, повторный request_id, историческая цена, административное изменение даты и строки, удаление/повторное удаление и возврат остатка. Машинный результат: `windows-integration-checks.json`.
- Во входных XLSX сохранены оригинальные байты и явно разобраны три вида несовпадения названий. Для ФИО БД хранит фамилию, имя и отчество отдельно, а приложение собирает отображаемое ФИО запросом.
- 11 Node-проверок подтверждают исходный импорт и FK, все 30 наборов, независимо пересчитанные цены и остатки на 15.05.2026, четыре задания/75 баллов, учебные файлы, схему, таймер, отсутствие готового SQL в экзаменационных ZIP и совпадение исходных PDF/ZIP с ранее записанными SHA-256.
- Браузером пройдены 294 экрана: все 49 шагов при ширинах 390, 768 и 1440 в светлой и тёмной теме. Дополнительно проверены пауза/reload, завершение/блокировка, повтор с прошлым протоколом, 30 вариантов, ER и её справка, код примера, презентация и Back. Сохранены 42 обзорных снимка; ошибок JavaScript и общего горизонтального выхода не обнаружено. Машинный результат: `browser-checks.json`.
- В настоящих окнах Windows при текущем масштабе 200% пройдены гость → вход клиента → карточка → размер/количество → корзина → подтверждение. Созданный заказ появился в списке администратора. Проверено предупреждение при смене пользователя с незавершённой корзиной. Снимки в `materials/screens` содержат исходные пиксели Windows, без дорисовки.
- После выявленного переноса цены в Windows исправлены масштабирование при добавлении динамических карточек, ширина цены, таблицы с переносом длинного названия и подключение исходной иконки. ER PDF отрисован и осмотрен; таблицы и поля читаемы.

## Границы

Полный маршрут создания каждого файла через окна Visual Studio заново на чистой VM не пройден. Снимки рабочих приложений иллюстрируют названные состояния; они не доказывают каждое действие в меню Visual Studio. Следующий учебный этап — такой буквальный проход и доработка микрошагов по обнаруженным затруднениям.

Проверки на Windows 100% и 150% отдельно не выполнялись. Все 30 отдельных программных решений не разрабатывались и не запускались; проверены согласованность их входных комплектов и контрольные результаты. Рабочий пример пока один: WinForms + MySQL/MariaDB. WPF/PostgreSQL не заявляются как реализованные.

Самоотметки не проверяют код и не начисляют экзаменационные баллы. Пробный режим — локальная учебная тренировка с непрерывным временем, не прокторинг. Артефакт Windows зависит от .NET Desktop Runtime 10; он не объявляется автономным установщиком.

Рабочие базы пользователя не изменялись: использовались только отдельные `prog_demo_checks_*` и `prog_demo_play_*`. Параметры подключения брались из локального закрытого профиля VM, не сохранены в исходниках, отчётах или архивах.

## Повторение

`npm run build`, `npm test`; Windows: Release Build решения `ProgDemo.sln`. Для чистых проверок — стартовый проект `ProgDemo.Checks` без переменной подключения. Для интеграции сначала импортировать sample.sql в новую отдельную БД с префиксом `prog_demo_checks`, затем задать `PROG_DEMO_CONNECTION` только в локальном профиле и запустить тот же проект.

Доказательства браузера создаёт `scripts/browser_qa.cjs` с установленным Playwright и доступным локальным сервером 4209. В GitHub Actions сборка Windows и чистые проверки автоматизированы; живой сервер MySQL в CI не подменяется имитацией.
