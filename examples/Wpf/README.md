# Чудо Обувь · WPF + PostgreSQL

Пример для четырёх заданий базового уровня КИМ 09.02.07-2-2027. Гость просматривает каталог. Покупатель входит по логину, ищет и сортирует модели, выбирает размеры и подтверждает заказ. Менеджер ведёт заказы клиентов. Администратор дополнительно изменяет даты и удаляет строки заказов.

Каталог суммирует остатки по размерам. Скидка зависит от истории за предыдущий календарный месяц. Транзакция сохраняет заказ и списывает остатки вместе.

Порядок восстановления базы и запуска приведён в [инструкции](../../docs/launch-postgresql.html).
