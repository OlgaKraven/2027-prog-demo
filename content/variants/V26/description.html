Магазин сумок для спорта

Магазин ведёт каталог моделей с размерами и принимает заказы покупателей. Размер указан как длина, см.

  • Зал. сумка с боковым карманом, сумка для обуви, сумка с плечевым ремнём, спортивная сумка с жёстким дном.
  • Бассейн. непромокаемая сумка, сумка с сетчатым карманом, сумка с отделом для мокрых вещей, сумка на молнии.
  • Поездки. дорожная сумка, сумка с наружной стяжкой, складная сумка.

Файлы CSV описывают модели, размерные остатки, покупателей, заголовки и строки заказов. История заказов уже учтена в исходных остатках.
