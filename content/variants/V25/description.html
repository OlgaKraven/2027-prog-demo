Магазин чехлов для техники

Магазин ведёт каталог моделей с размерами и принимает заказы покупателей. Размер указан как внутренняя ширина, см.

  • Планшеты. мягкий чехол, чехол с клапаном, чехол на молнии, чехол с карманом.
  • Ноутбуки. чехол с ручкой, чехол с усиленным углом, чехол с ремнём, чехол с мягкой подкладкой.
  • Аксессуары. чехол для клавиатуры, чехол для кабелей, чехол для блока питания.

Файлы CSV описывают модели, размерные остатки, покупателей, заголовки и строки заказов. История заказов уже учтена в исходных остатках.
